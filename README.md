# AI Chatbot using Python and Gemini

## About The Project

This project is a simple AI chatbot built using Python, Streamlit, and Google's Gemini API. Users can enter questions through a web interface and receive AI-generated responses.

## Built With

- Python
- Streamlit
- Google Gemini API
- python-dotenv

## Features

- Simple chatbot interface
- AI-generated responses using Gemini
- Secure API key handling using environment variables
- Web interface using Streamlit

## Installation

### 1. Clone the Repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
cd AI-Chatbot-using-Python

### 2. Create a Virtual Environment
python -m venv venv

### 3. Install Dependencies
pip install -r requirements.txt

### 4. Configure API Key

Create a .env file in the project folder:

GEMINI_API_KEY=your_api_key_here

Do not share or upload the .env file.

### 5. Run the Application
streamlit run app.py

The chatbot will open in your browser.
